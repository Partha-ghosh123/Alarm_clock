# ⏰ Alarm Clock Web Application

A sleek, responsive, and intuitive **Alarm Clock** web application built using vanilla frontend technologies. It allows users to track the current time in real-time, set custom alarms, and receive immediate audio or visual alerts when the time is reached.

🔗 **[Live Demo](https://alarm-clock-sand.vercel.app)** 

---

## 🚀 Features

* **Real-Time Clock:** Displays the current time with precision, updated continuously every second.
* **Custom Alarm Setter:** Easily configure the exact hour and minute for your alarm.
* **Responsive UI/UX:** Fully optimized for all screen sizes, including mobile, tablet, and desktop environments.
* **User-Friendly Design:** Minimalist, clean, and intuitive layout for a seamless user experience.

---

## 🛠️ Technologies Used

The project is built entirely with vanilla web technologies to ensure lightweight performance and fast loading times:

| Technology | Purpose |
| :--- | :--- |
| **HTML5** | Structures the application elements and layout. |
| **CSS3** | Handles modern styling, responsiveness, and visual presentation. |
| **JavaScript (ES6)** | Powers the core logical engine, time checking, and alarm functionality. |
